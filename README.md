## What This Project Is

A full-cycle ISO 27001:2022 internal audit simulation for TrustPay Ltd,
a fictional fintech company. Built to demonstrate practical GRC and 
audit competency across every stage of the audit lifecycle.

---

## What's Inside

| Sheet | What It Shows |
|---|---|
| 1. Audit Plan | Scope, objectives, clause coverage, audit methods |
| 2. Evidence Checklist | 25 evidence items — requested, received, assessed |
| 3. Findings Register | 7 findings with root cause and corrective actions |
| 4. Corrective Action Tracker | 12 actions with owners, deadlines, and status |
| 5. Audit Summary Dashboard | Executive summary with ISMS conformance verdict |

---

## Key Findings

- **Major NC:** 7 of 11 suppliers had no IS risk assessment (A.5.19)
- **Minor NC:** 28% of staff overdue on security awareness training (A.6.3)
- **Minor NC:** Privileged access review overdue by 6 weeks (A.5.15)
- **Minor NC:** 3 ex-employee accounts not deactivated within SLA (A.5.15)
- **OFI:** Disaster Recovery Plan untested for 18 months
- **OFI:** 3 ISMS KPIs missing baseline data
